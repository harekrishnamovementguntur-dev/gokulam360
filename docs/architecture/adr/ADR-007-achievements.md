# ADR-007: Attach Achievements to Memberships

**Status:** Accepted

## Problem

Recognition, milestones, results, certificates, and progress should survive term and batch changes.

## Alternatives

1. Attach achievements to terms.
2. Attach achievements directly to students.
3. Attach achievements to memberships with optional term/offering references.

## Decision

Achievements belong to Memberships and may optionally reference an offering, term, session, certificate, or source event.

## Consequences

Achievement history follows the student-program relationship while retaining context for reports, badges, certificates, and parent dashboards.
